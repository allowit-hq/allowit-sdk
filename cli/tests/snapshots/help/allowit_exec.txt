Submit an agent request: the policy checks it and the rail settles it

Usage: allowit exec [OPTIONS] --op <OP> --to <ADDR> --amount <AMOUNT>

Examples:
  allowit exec --op transfer --to GDEST… --amount XLM:5
  allowit exec --op transfer --to GDEST… --amount XLM:5 --request-id pay-001 --wait 2m
  allowit exec --op transfer --to GDEST… --amount 50000000 --build-only

Options:
      --op <OP>                transfer, swap, deposit, redeem, custom, custom.FN or custom:C….FN
      --to <ADDR>              The recipient address
      --amount <AMOUNT>        CODE:DECIMAL, CODE:ISSUER:DECIMAL, C…:DECIMAL or INTEGER base units
      --token-out <ASSET:MIN>  The asset and minimum to receive, for swap: ASSET:MIN
      --args <JSON>            Call arguments as a JSON object, for custom operations
      --request-id <ID>        Request ID; a retry reuses it [default: a new ID, printed on stderr]
      --wait <DUR>             Wait up to DUR for a final result [default: 60s]
      --build-only             Print the unsigned request and send nothing (sign it elsewhere, then
                               tx send)
  -h, --help                   Print help

Global options:
  -n, --rail <RAIL>       Rail as CAIP-2 or alias: stellar:testnet, solana:devnet, tempo:testnet
                          [env: ALLOWIT_RAIL] [alias: --network]
      --wallet <ADDR>     Policy wallet address: C… on Stellar, a vault on Solana, 0x… on Tempo
                          [env: ALLOWIT_WALLET]
      --output <FORMAT>   Output format [possible values: text, json]
      --json              Same as --output json
  -y, --yes               Confirm destructive actions without a prompt
  -q, --quiet             Print no progress on stderr
  -v, --verbose           Print the resolved rail, wallet and config directory on stderr
      --no-color          Disable color (NO_COLOR also disables it)
      --config-dir <DIR>  Config directory [default: $XDG_CONFIG_HOME/allowit or ~/.config/allowit]
                          [env: ALLOWIT_CONFIG_DIR]
      --rpc-url <URL>     RPC URL override for the selected rail
