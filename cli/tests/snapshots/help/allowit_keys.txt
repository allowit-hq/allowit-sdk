Manage local keys and select the signing key

Usage: allowit keys [OPTIONS] <COMMAND>

Examples:
  allowit keys generate agent
  allowit keys add owner --public-key PUBLIC_KEY
  allowit keys ls
  allowit keys use agent
  allowit keys show agent

Commands:
  generate  Generate a private signing key for the selected rail
  add       Record a public key that this device cannot sign for, such as the owner's
  import    Import a private key in the selected rail's signer format
  ls        List keys [alias: list]
  show      Show a key's public metadata
  use       Select an existing private key for requests on the current rail
  fund      Fund a key's account through the selected rail's test faucet
  export    Print a private key in the rail's signer format
  rm        Remove a key and its private key file
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

Global options:
  -n, --rail <RAIL>       Rail identifier or alias from rail ls [env: ALLOWIT_RAIL] [alias:
                          --network]
      --wallet <ADDR>     Wallet address accepted by the selected rail [env: ALLOWIT_WALLET]
      --output <FORMAT>   Output format [possible values: text, json]
      --json              Same as --output json
  -y, --yes               Confirm destructive actions without a prompt
  -q, --quiet             Print no progress on stderr
  -v, --verbose           Print the resolved rail, wallet and config directory on stderr
      --no-color          Disable color (NO_COLOR also disables it)
      --config-dir <DIR>  Config directory [default: $XDG_CONFIG_HOME/allowit or ~/.config/allowit]
                          [env: ALLOWIT_CONFIG_DIR]
      --rpc-url <URL>     RPC URL override for the selected rail
