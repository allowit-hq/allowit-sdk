AllowIt: policy wallets for agents. Go on. On your terms

Usage: allowit [OPTIONS] [COMMAND]

Examples:
  allowit rail use stellar:testnet
  allowit keys generate agent --fund
  allowit setup --agent agent
  allowit exec --op transfer --to GDEST… --amount XLM:5
  allowit status pay-001 --wait 60s

Commands:
  setup       Set up the current rail: the agent key and the paid-service asset
  whoami      Show the current rail, agent key, default wallet and engine account
  keys        Manage local keys: generate, add, import, list, fund, export and remove
  rail        List rails, show what a rail supports and choose the current rail
  config      Show the configuration and where it lives
  wallet      Create, select, fund and manage policy wallets
  policy      Write, check, build, test, show and deploy policies
  exec        Submit an agent request: the policy checks it and the rail settles it
  eval        Ask the policy whether a request would pass. Never signs or spends
  status      Read a request's state. The local journal supplies its rail and wallet; --wallet is
              the fallback
  history     List recent requests from the local journal
  tx          Submit transactions that were signed outside the CLI
  skills      Search and inspect the paid-service catalog
  call        Call a paid service by catalog ID or URL
  curl        Send a paid HTTP request with curl syntax (-X, -H, -d, --data-raw, -o)
  http        Send a paid HTTP request with HTTPie syntax (METHOD URL NAME=VALUE...)
  mcp         Run the MCP server for paid services on stdin and stdout
  claude      Run Claude Code with the AllowIt MCP server. Needs a Claude subscription sign-in;
              API-key settings are removed
  codex       Run Codex with the AllowIt MCP server. Needs a ChatGPT sign-in; API-key settings are
              removed
  lsp         Run the policy language server: diagnostics, hover, completion and allowit/workflow
  completion  Print a shell completion script
  guide       Print the agent guide: the commands in the order an agent uses them
  version     Print the version
  help        Print this message or the help of the given subcommand(s)

Options:
  -h, --help     Print help
  -V, --version  Print version

Global options:
  -n, --rail <RAIL>       Rail as CAIP-2 or alias: stellar:testnet, solana:devnet, tempo:testnet
                          [env: ALLOWIT_RAIL] [alias: --network]
      --wallet <ADDR>     Policy wallet address: C… on Stellar, a vault on Solana, 0x… on Tempo
                          [env: ALLOWIT_WALLET]
      --output <FORMAT>   Output format [possible values: text, json]
      --json              Same as --output json
  -y, --yes               Confirm destructive actions without a prompt
  -q, --quiet             Print no progress on stderr
  -v, --verbose           Print the resolved rail, wallet and config directory on stderr
      --no-color          Disable color (NO_COLOR also disables it)
      --config-dir <DIR>  Config directory [default: $XDG_CONFIG_HOME/allowit or ~/.config/allowit]
                          [env: ALLOWIT_CONFIG_DIR]
      --rpc-url <URL>     RPC URL override for the selected rail

Exit codes:
  0 ok, 1 internal error, 2 usage error, 3 configuration or not supported on
  this rail, 4 rejected by the contract, 5 uncertain (retry with the same ID),
  6 replayed, 10 owner signature needed, 11 waiting for owner input,
  12 pending, 20 denied by the policy, 130 interrupted
