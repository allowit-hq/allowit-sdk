Create, select, fund and manage policy wallets

Usage: allowit wallet [OPTIONS] <COMMAND>

Examples:
  allowit wallet create --kind common --asset XLM --policy policy.rs --owner owner --agent agent
  allowit wallet use CWALLET…
  allowit wallet fund XLM:200 --from owner
  allowit wallet show

Commands:
  create    Create a policy wallet with a policy, an owner and an agent
  ls        List the wallets this device knows on the current rail [alias: list]
  show      Show the wallet: its roles, asset and state
  use       Make an address the current rail's default wallet
  fund      Add funds to the wallet
  withdraw  Move funds from the wallet to the owner
  update    Replace the owner or the agent, or switch x402 payments
  pause     Stop agent spending until the owner resumes it
  resume    Let the agent spend again after a pause
  close     Close the wallet and return its funds to the owner
  help      Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

Global options:
  -n, --rail <RAIL>       Rail as CAIP-2 or alias: stellar:testnet, solana:devnet, tempo:testnet
                          [env: ALLOWIT_RAIL] [alias: --network]
      --wallet <ADDR>     Policy wallet address: C… on Stellar, a vault on Solana, 0x… on Tempo
                          [env: ALLOWIT_WALLET]
      --output <FORMAT>   Output format [possible values: text, json]
      --json              Same as --output json
  -y, --yes               Confirm destructive actions without a prompt
  -q, --quiet             Print no progress on stderr
  -v, --verbose           Print the resolved rail, wallet and config directory on stderr
      --no-color          Disable color (NO_COLOR also disables it)
      --config-dir <DIR>  Config directory [default: $XDG_CONFIG_HOME/allowit or ~/.config/allowit]
                          [env: ALLOWIT_CONFIG_DIR]
      --rpc-url <URL>     RPC URL override for the selected rail
