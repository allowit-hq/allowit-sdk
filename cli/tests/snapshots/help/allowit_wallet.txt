Select and inspect installed Stellar policy wallets

Usage: allowit wallet [OPTIONS] <COMMAND>

Examples:
  allowit wallet use CWALLET…
  allowit wallet show

Commands:
  ls    List the wallets this device knows on the current rail [alias: list]
  show  Show the wallet: its roles, asset and state
  use   Make an address the current rail's default wallet
  help  Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

Global options:
  -n, --rail <RAIL>       Stellar rail: stellar:testnet or stellar:pubnet [env: ALLOWIT_RAIL]
                          [alias: --network]
      --wallet <ADDR>     Stellar wallet address (G… classic account or C… policy contract) [env:
                          ALLOWIT_WALLET]
      --output <FORMAT>   Output format [possible values: text, json]
      --json              Same as --output json
  -y, --yes               Confirm destructive actions without a prompt
  -q, --quiet             Print no progress on stderr
  -v, --verbose           Print the resolved rail, wallet and config directory on stderr
      --no-color          Disable color (NO_COLOR also disables it)
      --config-dir <DIR>  Config directory [default: $XDG_CONFIG_HOME/allowit or ~/.config/allowit]
                          [env: ALLOWIT_CONFIG_DIR]
      --rpc-url <URL>     RPC URL override for the selected rail
