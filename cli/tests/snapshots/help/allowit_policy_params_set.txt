Change parameters. Keys: transaction_cap, spent_cap, day_spent_cap, day_total_cap (amounts),
call_cap (a count), recipients (addresses), tokens (assets), expiry (RFC 3339 time or duration),
operations

Usage: allowit policy params set [OPTIONS] <KEY=VALUE>...

Examples:
  allowit --rail solana:devnet policy params set day_spent_cap=USDC:50 --sign-with-key owner
  allowit --rail solana:devnet policy params set transaction_cap=USDC:10 day_spent_cap=USDC:100 --sign-with-key owner

Arguments:
  <KEY=VALUE>...  KEY=VALUE pairs; a list value replaces the old list

Options:
  -h, --help  Print help

Signing:
      --sign-with-link       Print the owner signing link on stderr (the default)
      --sign-with-key <KEY>  Sign with a local key (testnet and development)
      --build-only           Write the unsigned transaction to stdout
      --wait <DUR>           Wait up to DUR for the owner to sign

Global options:
  -n, --rail <RAIL>       Rail as CAIP-2 or alias: stellar:testnet, solana:devnet, tempo:testnet
                          [env: ALLOWIT_RAIL] [alias: --network]
      --wallet <ADDR>     Policy wallet address: C… on Stellar, a vault on Solana, 0x… on Tempo
                          [env: ALLOWIT_WALLET]
      --output <FORMAT>   Output format [possible values: text, json]
      --json              Same as --output json
  -y, --yes               Confirm destructive actions without a prompt
  -q, --quiet             Print no progress on stderr
  -v, --verbose           Print the resolved rail, wallet and config directory on stderr
      --no-color          Disable color (NO_COLOR also disables it)
      --config-dir <DIR>  Config directory [default: $XDG_CONFIG_HOME/allowit or ~/.config/allowit]
                          [env: ALLOWIT_CONFIG_DIR]
      --rpc-url <URL>     RPC URL override for the selected rail
